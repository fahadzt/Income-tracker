# Income Tracker (iOS SwiftUI)

Premium dark-mode SwiftUI dashboard inspired by Apple Wallet / Revolut.

## What’s in this repo

- `Dashboard.swift`: SwiftUI dashboard + placeholder data + subtle animations.

## Run in Xcode

1. Open Xcode → **File** → **New** → **Project…** → **iOS App**
2. Set **Interface: SwiftUI**, **Language: Swift**
3. Replace the generated `App` / `ContentView` with the content of `Dashboard.swift`
4. Run (⌘R) or open Canvas previews
